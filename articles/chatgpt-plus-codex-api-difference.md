# 开了ChatGPT Plus，为什么API余额还是0？Plus、Codex和API别再混了

不少用户开通ChatGPT Plus后，都会遇到一个疑问：

明明已经付费了，为什么打开API平台，余额还是0？  
为什么Codex还能使用，但API调用却提示需要充值？

其实不是订阅没有生效，而是把ChatGPT、Codex和API混成了同一个产品。

## 一、ChatGPT Plus主要对应聊天产品

ChatGPT Plus是ChatGPT网页端和客户端中的个人订阅套餐。

开通后，主要提升的是ChatGPT里的模型、文件处理、图片生成、研究工具以及其他功能的使用体验和额度。

也就是说，你支付的订阅费用，主要对应的是ChatGPT产品本身，而不是给API账户充值。

所以，Plus已经正常开通，但API平台余额仍然为0，是很常见的情况。

## 二、API是单独计费的开发服务

API主要面向需要把模型接入网站、软件、小程序或自动化工具的开发者。

例如：

- 在自己的网站里加入智能客服；
- 批量处理文本和数据；
- 在程序中调用模型；
- 开发自己的AI应用；
- 将模型接入现有业务系统。

API和ChatGPT使用不同的账单系统。

即使已经订阅ChatGPT Plus，API平台也不会自动增加余额。需要使用API时，仍然要在API平台单独设置付款方式，并按照实际调用量计费。

## 三、Codex又属于另一种使用场景

Codex主要用于编程和软件开发，可以帮助用户阅读项目、修改代码、运行任务和检查改动。

目前，Codex可以通过ChatGPT账号使用，不同套餐拥有的使用额度不同。

因此，开通Plus后能够使用Codex，并不代表同时获得了API余额。

可以简单理解为：

| 产品 | 主要用途 | 费用关系 |
|---|---|---|
| ChatGPT Plus | 聊天、写作、文件、图片等 | 按订阅套餐使用 |
| Codex | 编程和项目任务 | 按ChatGPT套餐获得相应额度 |
| API | 接入网站、软件和程序 | 单独开通并按量计费 |

## 四、为什么很多新用户会搞混？

主要是因为这几个产品都使用同一个OpenAI账号登录，而且都能调用模型。

但账号相同，不代表账单和额度完全互通。

就像同一个账号可以登录多个服务，但每个服务对应的功能、额度和付款方式不同。

所以升级之前，最好先明确自己的需求。

如果只是聊天、写文章、处理文件或生成图片，主要看ChatGPT套餐。

如果需要使用AI辅助修改项目代码，可以关注Codex额度。

如果准备开发网站、应用或自动化程序，则需要了解API计费。

## 五、怎么判断自己到底需要哪个？

普通用户一般使用ChatGPT就够了。

每天高频使用、经常处理文件和复杂任务的人，可以根据实际使用情况考虑Plus或更高套餐。

开发者如果只是偶尔使用Codex修改代码，可以先使用套餐内额度；如果需要把模型接入自己的产品，则需要单独开通API服务。

不要因为看到“API余额为0”，就认为自己的Plus订阅失效了。

先回到ChatGPT的套餐或账单页面，检查订阅状态是否正常。API账单则需要到API平台单独查看。

## 写在最后

ChatGPT Plus、Codex和API虽然都和AI模型有关，但并不是同一个付费入口。

记住一句话就够了：

ChatGPT订阅用于ChatGPT，Codex额度跟随相应套餐，API则是单独计费。

把这三个产品分清楚，再选择套餐和付款方式，就不容易出现开通后发现“买错了”的情况。
